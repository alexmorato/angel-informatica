📌 Resumen de la sesión

✅ Presentación del ciclo medio: repasamos las asignaturas del título de Microinformática y Redes. Me las llevo para preparar ejercicios adelantados.

✅ Análisis de la web "Cine": vimos una web con cartelera, compra de películas y panel admin. Detectamos que el historial de compra se guardaba en localStorage del navegador, pero las películas nuevas añadidas desde el admin no persistían (solo se modificaba el HTML en memoria).

✅ Estructura web: identificamos las tres partes principales: CSS (estilos) dentro de <style>, HTML (estructura) en el body con divs, y JavaScript (interactividad) dentro de <script>.

✅ Publicación con GitHub Pages: subimos la web a un repositorio en GitHub, activamos GitHub Pages y conseguimos una URL pública para compartir con toda la familia. También creamos un index.html con IA (tres botones de cuenta atrás) y vimos el retraso de ~30 segundos en la publicación.

🧠 Conceptos fundamentales que hemos visto
📄 Fichero HTML
En local: doble clic → el navegador renderiza el archivo, pero solo visible en tu equipo.
En servidor web: alojado en un servidor, accesible desde cualquier dispositivo con URL. index.html es el archivo por defecto al acceder a una carpeta.
🗃️ JSON & localStorage
En la web del cine, el historial de compras se guardaba como una estructura JSON (JavaScript Object Notation) dentro del localStorage. JSON es un formato ligero para intercambiar datos, muy usado en desarrollo web.
📋 Listas en JavaScript
En el código JS teníamos una lista (array) de películas. El script recorría esa lista y generaba dinámicamente secciones <div> dentro del HTML para mostrar la cartelera. Así se modifica el DOM de forma dinámica.
🎨 3 pilares de la web
• CSS (estilos): apariencia visual, colores, maquetación.
• HTML (estructura): etiquetas como <div>, <h1>, <button>.
• JavaScript: lógica, interactividad, modificar el HTML en tiempo real.
🔁 Git & repositorio
Git es un sistema de control de versiones que registra los cambios en el código. Un repositorio es el lugar donde se guarda todo el historial de un proyecto. Nos ayuda a organizar y colaborar sin perder trabajo.
🐙 GitHub
Plataforma web que ofrece repositorios gratuitos en la nube. Permite alojar proyectos y gestionar el código con Git. Es como un "Dropbox para programadores" pero con control de versiones.
🌐 GitHub Pages
Servicio que convierte tu repositorio en un servidor web estático. Cada vez que haces un commit, GitHub Pages despliega automáticamente los cambios y genera una URL pública como: usuario.github.io/repo/
📌 Commit
En Git, un commit es una "instantánea" de los cambios realizados. Cada commit guarda una versión con un mensaje descriptivo. Es como un punto de guardado con historia.
💾 localStorage
Almacenamiento persistente en el navegador (hasta 5-10 MB). Permite guardar datos aunque cierres la pestaña. Ideal para preferencias o historiales sin base de datos. En la web del cine guardaba las compras.
⚙️ Despliegue (deploy)
Hacer que tu código pase de tu ordenador a un servidor accesible para todos. Con GitHub Pages, cada commit desencadena un despliegue automático. Vimos el pequeño retraso de ~30 segundos hasta que se actualiza la web.
🛠️ Lo que hicimos paso a paso

🔹 1. Revisión del código fuente: Inspeccionamos el HTML, CSS y JS de la web del cine. Localizamos la función que añadía películas (solo modificaba el DOM, sin guardar en localStorage).

🔹 2. GitHub y primer repositorio: Creamos repositorio "pruebas" desde la web de GitHub. Subimos el archivo cine.html mediante la interfaz web (commit inicial).

🔹 3. GitHub Pages activado: Fuimos a Settings → Pages, seleccionamos rama main y carpeta raíz. Nos dio una URL tipo https://[usuario].github.io/pruebas/cine.html.

🔹 4. Crear index.html con IA: Usamos ChatGPT para generar una página con tres botones (cuenta atrás 10, 30, 60 min). La guardamos como index.html dentro del mismo repositorio y la subimos con nuevo commit.

🔹 5. Efecto Pages + Tiempo de propagación: Comprobamos que la nueva página no estaba visible inmediatamente, sino después de ~30 segundos (tiempo que tarda GitHub Pages en reconstruir y desplegar).

🔹 6. Compartir: Enviamos la URL a familiares para que accedieran desde el móvil/ordenador a la web pública del cine.

📦 JSON, listas y manipulación del DOM
🧩 JSON (JavaScript Object Notation)
Formato de texto para estructurar datos. En el cine, el historial de compras tenía pinta de algo como:
{"compras": [{"pelicula":"Dune", "fecha":"..."}]}
Lo guardaban en localStorage y lo recuperaban al recargar.
🔄 Modificar HTML con JS
JavaScript puede crear nuevos elementos <div> y añadirlos al DOM. En la web del cine, al añadir película, se generaba dinámicamente un nuevo div con los datos, pero sin persistencia. Mejora posible: guardar también en localStorage.
🏗️ index.html: punto de entrada
Cuando un servidor web recibe una petición a una carpeta (ej: https://midominio/miweb/) busca automáticamente index.html. Es la página principal por defecto. Por eso renombramos o creamos ese archivo.
