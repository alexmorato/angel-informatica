2. Revisión de prácticas

Se analizó una web tipo cine con funcionalidades:

  • Ver cartelera
  • Comprar películas
  • Acceso administrador
  • Añadir nuevas películas
🧠 Local Storage
  • Espacio de almacenamiento en el navegador
  • Guarda datos de forma persistente
  • Se mantiene tras recargar la página (F5)

3. Comportamiento de la web

  • Las películas añadidas modificaban el HTML directamente
  • No se guardaban de forma persistente
  • Se perdían al recargar
Comparativa
  • HTML dinámico: cambios temporales
  • LocalStorage: datos persistentes

4. Estructura de una página web

  • HTML (body): estructura (div, botones…)
  • CSS (style): estilos visuales
  • JavaScript (script): lógica e interactividad

5. Publicación web

Los archivos HTML en local solo funcionan en ese ordenador.

Para que otros puedan acceder, deben estar en un servidor web.

6. Ejercicio con GitHub

7. index.html

📚 Conceptos aprendidos

HTML

Archivo que define la estructura de una web. En local funciona solo en tu ordenador, pero en un servidor web es accesible desde internet.

JSON

Estructura de datos usada para guardar información (por ejemplo, historial de compras). Puede ser una lista de elementos que luego JavaScript recorre.

JavaScript

Permite modificar el HTML dinámicamente (añadir elementos como divs) e interactuar con el usuario.

Repositorio

Carpeta donde se guarda el código de un proyecto.

Git

Sistema para controlar cambios en el código y subirlos a un repositorio.

GitHub

Plataforma que permite guardar repositorios en la nube.

GitHub Pages

Servicio que publica automáticamente tu web en internet.

Commit

Acción de guardar cambios en un repositorio.

Local Storage

Almacenamiento del navegador que guarda datos de forma persistente.
